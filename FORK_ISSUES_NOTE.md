# Note: Issues are not available on this fork

GitHub disables the Issues tab by default on forked repositories. If you would like to report a bug, request a feature, or start a discussion, please **open issues on the upstream repository**:

**https://github.com/pingdotgg/t3code/issues**

Alternatively, if you are the maintainer of this fork and would like to enable issues here, you can do so by navigating to:

**Settings > General > Features > Issues** and checking the box to enable them.

This note is left here as a PR to bring this to the maintainer's attention.
